## Hardware and Components
- Arduino/Elegoo UNO R3
- Breadboard
- Wires
- Buttons (7)
- Passive Buzzer (1)

| Function | Arduino Pin(s) | Component |
|-----------|-------------|-------------|
| Input | Pins 2 to 8 | Buttons |
| Output | Pin 9 | Passive Buzzer |
| V<sub>cc</sub> | 5V | Breadboard |
| Ground | GND | Breadboard |
